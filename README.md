# Polymarket

Local-first AI-powered prediction market operating system.

## Vision

A modular local trading/research platform for:
- Kalshi
- Polymarket
- AI-assisted market analysis
- Arbitrage detection
- Agent consensus systems
- Risk management
- Backtesting

## V1 Goals

- Local web dashboard
- Live market feeds
- Portfolio tracking
- AI recommendations
- Suggest-only trading mode
- Plugin-ready architecture
- SQLite persistence

## Planned Stack

### Frontend
- React
- Vite
- TypeScript
- Tailwind

### Backend
- Node.js
- Fastify
- WebSockets

### Storage
- SQLite

## Architecture

```text
Browser UI
   ↓
Local API Server
   ↓
Agent Engine
   ↓
Exchange Adapters
   ↓
Kalshi / Polymarket APIs
```
